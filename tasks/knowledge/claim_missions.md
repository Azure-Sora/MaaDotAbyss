# 任务页面（任務）知识卡

## 入口与标签
- 主页 → 右侧"任务"按钮（约 1205,415）进入任务页面。
- 顶部标签：デイリー（每日）/ ウィークリー（每周）/ 期間限定 / 実績。
- 右下"一括受け取り"（一键领取）：**只对当前标签有效**，灰色=该标签没有可领的。
  每日任务通常用它；每周任务它常为灰色，需逐个点 GET。

## 领取操作
- 可领取任务的"GET"按钮为蓝色高亮，位于任务条目右侧（x≈1145）。
- 已完成待领的任务显示"達成 n/n"；未完成的显示"あと N 日"（还差 N 天）——有"あと"字样的也可能已达成可领，以 GET 是否高亮为准。
- 点 GET → 弹出获得物品画面 → 点画面任意处/OK/次へ 关闭 → 回任务列表领下一个。
- 若某 GET 点了两次都没反应，跳过它领下一个，最后再试一次。
