1. 执行方式：导航到探索队页后调 auto(expedition_sweep)，程序自动把第一个探索任务的免费次数打完；LLM 不要自己连打。
2. 入口路径：主页 → 底部导航"探索队" → 探索队页面右侧「探索クエスト」按钮（约1142,481，"N件発生!"）。
3. 【消费红线】免费次数耗尽会弹"消費して…復させますか"恢复确认——一律「キャンセル」拒绝，绝不点「決定」/「購入」；程序会自动拒绝并视为完成。
4. 不要点「第N階層を探索」——那是挂机探索队派遣（弹窗标题"探索先を変更"），不是探索任务；误点就点右上角X关闭。
5. 程序回报 done → 探索队页面点底部导航"主页"返回 → report done。
6. 程序回报 partial → 按 detail 接手：任务详情打不开就重开列表（点探索クエスト按钮）；战斗失败换下一任务或直接完成。
7. 【机制】所有探索任务共享同一免费次数池：各卡「挑戦回数【N/3】」显示同一个数字，打完一个任务它会消失、下一个顶上；N=0 表示今日免费次数已尽。
8. 日文对照：探索クエスト=探索任务、開始=开始、挑戦回数=挑战次数、キャンセル=取消。
9. 严禁点击抽卡或亲密度页面；网络错误立即 report blocked。
