- 执行方式：导航到勢力クエスト列表页后调 auto(forces_sweep)，程序自动清剿全部开放关卡；LLM 不要自己逐场打。
- 入口路径（本次实跑验证通畅）：主页 → 底部导航“冒险”(约823,648) → 冒险页面点「勢力クエスト」(约960,344)。
- 列表页判据：标题“勢力クエスト”，5张关卡卡横排；灰卡写「現在依頼はありません」=未开放；开放卡每日轮换（Peldion/千国連合/Luxnova/Milesgard 均出现过），以卡片挑戦回数/可用状态为准，勿硬编码关卡名。
- 刚进列表页右下角可能残留 NOW LOADING 提示，先 wait 等加载消失再调 auto，避免程序误判场景。
- auto 回报格式：done 带 cleared=N 及 [('关卡名', 剩余次数)] 列表，如 [('Peldion', 0)] 表示该关已清至 0/3；cleared=0 属正常（当日已清完，挑戦回数 0/3），cleared>0 即本次清剿成功，直接继续返回步骤。
- 返回主页路径：列表页无底部导航，先点左上◆(约46,35)回冒险页，再点底部导航“主页”(约122,655)。
- 程序回报 partial → 常见原因：某关战斗失败（计数不递减）或结算卡住；接手时看各卡「挑戦回数 N/3」，N=0 的卡已完成。
- 误入主线任务页（标题不同）→ 点左上◆返回冒险页重进。
- 战斗中「自動分解確認」弹窗程序会自动处理；若 LLM 接手遇到则点「分解する」，随后「分解報酬」弹窗点右上角X。
- 周回(Button_SkipMode)按钮禁用——拿了不全奖励，程序只走出撃单刷，属预期行为。
- 返回主页后可能弹出限时售卖推广弹窗（時間限定販売、DMMポイント购买），属消费类页面：点右上角X(约1234,34)关闭，绝不点购买。
- 严禁点击抽卡或亲密度页面；网络错误弹窗（403/通信エラー等）立即 report blocked。
