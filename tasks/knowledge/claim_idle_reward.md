- 挂机奖励入口：主界面右下角大宝箱图标，精确位置约 (1140, 640)，图标下方带「MAXまで mm:ss」倒计时文字。
- 倒计时未满也可直接领取：点击宝箱即可进入「探索報酬」领取画面，无需等倒计时归零（实测 MAXまで 02:45 时仍可进）。
- 「探索報酬」结算画面底部「確認して次へ」是纯文本翻页提示而非按钮，click 会穿透到底下按钮，必须用 skip 整页跳过（实测有效）。
- 结算/翻页提示可能连续多页，skip 后若仍在结算画面可继续 skip；连续两次 skip 画面无变化则换明显控件（关闭X等）或报告。
- 领取后可能自动触发后续探索/战斗动画，无 UI 可点时用 wait/wait_stable 等待，看到目标按钮再 click。
- 日文对照：「MAXまで」=距上限时间；「確認して次へ」=确认并继续（纯文本）；「探索報酬」=挂机/探索奖励；「领取する」=领取。
- 绝对禁区：过程中不得点击任何「ガチャ」（抽卡）或「親密度/好感度」（亲密度）入口，即使路径看起来更短。
- 出现「自動分解確認」弹窗直接点「分解する」确认（用户已启用自动分解设置）。
- 消耗红线：凡「消費して…ますか」句式或含購買/回復/購入字样的确认弹窗，一律点「キャンセル」/右上X拒绝，绝不点「決定」「購入」。
- 出现通信エラー/ネットワークエラー/403 等错误弹窗时立即 report(status="blocked")，不做任何点击。
- 同一按钮点击后画面无变化不要重复超过 2 次，改用其他明显控件或报告。
