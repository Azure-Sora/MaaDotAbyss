# DotAbyss 日常自动化工具 · 前期调研

> 2026-08-29 ｜ 目标：为 DMM 游戏《DOT ABYSS（ドットアビスX）》做一个"多模态大模型决策 + 轻量 Agent 执行"的日常任务自动化工具，以 MaaFramework 为设备层。

## 一句话结论

**方案整体可行**：MAA 原生支持 Win32（后台截图+输入全齐）做设备层；自研几百行的 LLM 决策循环做大脑；游戏是"点 UI + 挂自动"的放置玩法，对 LLM 时延完全不敏感；成本（GLM-4.5V 约 ¥0.3~1/天，Flash 免费）与时延（1.5~5s/步）均在可接受范围。后台运行有三级递进方案，其中 BGI 式"子会话桌面分身"机制已从源码层面拆解清楚，可低成本的移植复用。

## 关键决策（已确认）

- **语言栈**：Python（MAA 官方绑定）
- **LLM 主力**：小米 MiMo-V2.5（OpenAI 兼容、原生图像理解；后续本地部署开源模型为备选路线）
- **后台策略**：前台先跑通（M0~M2），M3 再上后台（普通后台 → 子会话分身兜底）
- **使用形态**：CLI + YAML 配置起步，GUI 后置
