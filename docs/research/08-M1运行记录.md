## 2. 本次验证的机制（对架构的有效性证明）

1. **知识卡机制**：冒险页布局混乱时（agent 误入主线任务），人工看图写 10 行种子知识卡后，agent 立即直达目标；后续任务的知识卡自动沉淀质量良好（压缩、更新坐标、记录弹窗处理）。
2. **"探索→知识卡→复跑直达"闭环成立**：势力任务从 45 步零进展 → 种子卡 + 3 次续跑全清，且知识卡在 done 时自动更新。
3. **可续跑性**：战斗类任务超时中断后直接重跑即可接续（游戏内状态即进度）。
4. **异常自愈**：一次模型输出解析失败（空返回）在下一步自动恢复；误入错误页面后能自行退出重找。
5. **MiMo-V2.5 表现**：界面语义理解好（日文按含义处理、弹窗分类正确），动作坐标可用率较高；偶发幻觉（把主页认成冒险页、把台词气泡当遮挡）靠知识卡纠正。
