# 07 · 日常任务流程规格（用户口述整理）

> 2026-08-29 ｜ 来源：用户口述 ｜ 状态：M1 实现依据

## 0. 通用规则

- **日文按钮按语义理解**：界面为中文（汉化 Mod 覆盖）与日文（未覆盖）混排。Agent 不得因文字不匹配判定"按钮不存在"，须按含义对应（见 §2 词表）。
- **禁区**：抽卡页、角色亲密度页，任何情况下不得点击/进入。
- **战斗锚点**：右下角的 AUTO 与倍速按钮是"已进入战斗"的稳定锚点；但**部分任务进入战斗有入场动画**，动画期间这两个按钮不可见——不能一进战斗就判定"没进战斗"，要等动画（帧差稳定或按钮出现）。
- **通用停止条件**：打到"剩余次数为 0"或"打不过"（战斗失败）为止。

## 1. 流程（顺序执行）

| # | 任务 | 步骤 | 完成判据 |
| --- | --- | --- | --- |
| 1 | 领取挂机奖励 | 点主页面**右下角大宝箱**（附近有 MAX 倒计时文字）→ 领取 → 关闭弹窗回主页 | 主页可见、无弹窗 |
| 2 | 领取礼物 | 点右侧**"礼物"**按钮 → 领取全部附件 → 返回主页 | 礼物可领数量归零/回到主页 |
| 3a | 冒险·势力任务 | 主页点**"冒险"** → 选**"势力任务"** → 依次打今日开放的关卡（五大关每天开放其中几个，动态） | 每关剩余次数为 0，或战斗失败（打不过）即停 |
| 3b | 冒险·迎击战 | 冒险页 → **"迎击战"** → 打**下面三个小 boss** 各自的次数 | 三个 boss 均无剩余次数 |
| 4 | 探索队 | 主页点**"探索队"** → 右侧**"探索任务"** → 选**第一个** → 打到剩余次数 0 | 次数归零或打不过 |
| 5 | 任务一键领取 | 返回主页 → 点**"任务"** → 一键领取全部 | 领取完成回到任务页/主页 |

- 3a/3b 的出击准备页面布局略有不同，但共同点：**点击"出撃（出击）"按钮开始战斗**。
- 战斗中：确认 AUTO/倍速锚点存在 → 挂机等待 → 帧差稳定 + 画面切走 = 战斗结束。

## 2. 日文词表（语义对照，供 Agent 与知识卡引用）

| 日文 | 含义 | 出现场景 |
| --- | --- | --- |
| 出撃 | 出击 | 出击准备页的开始按钮 |
| 勢力任務 | 势力任务 | 冒险页入口 |
| 迎撃戦 | 迎击战 | 冒险页入口 |
| 探索任務 | 探索任务 | 探索队页右侧入口 |
| 任務 | 任务 | 顶部/侧边入口（注意与"勢力任務"区分） |
| プレゼント | 礼物（礼物盒） | 右侧礼盒按钮可能为日文 |
| 残り回数 / 回数 | 剩余次数 | 关卡卡片上的次数标识 |
| MAXまで / あと | 距离 MAX 还有 / 还剩 | 挂机宝箱倒计时、活动倒计时 |
| AUTO / 倍速 | 自动 / 加速 | 战斗右下角锚点（可能本身就是拉丁字） |
| ガチャ | 抽卡（**禁区**） | 底部导航"抽卡"位 |
| 好感度 / 親密度 | 亲密度（**禁区**） | 角色相关页面 |

## 3. 已知坑位

1. 入场动画期间 AUTO/倍速不可见（见 §0）。
2. 五大关"每天开放其中几个"→ 灰关/未开放标识需要识别，只打开放的。
3. 战斗失败（打不过）→ 停止该关卡，不要重试烧资源。
4. 领取类操作后常有获得物品弹窗，需要关闭（点空白/确认按钮）。
5. 偶发加载卡顿：连续点击无响应时先等待/做前台基线，勿误判为按钮不存在（见 06 文档 §2.5）。
6. 403/网络错误弹窗 → 立即停止整个流程并通知（见 05 文档 §6）。
